# Instalación rápida de APKs CIM v6.0
Para instalar en un dispositivo Android conectado por ADB:
`ash
adb install -r app-coordinador.apk
adb install -r app-plc.apk
adb install -r app-manufactura.apk
adb install -r app-calidad.apk
adb install -r app-almacen.apk
adb install -r wear-coordinador.apk
`
Si no usas ADB, copia los APKs a tu teléfono y ábrelos para instalarlos (activar fuentes desconocidas si es necesario).
