================================================================================
                           INSTRUCCIONES DE INSTALACIÓN
================================================================================

1. INSTALACIÓN DE APKs (5 minutos)
   - Ejecutar: 4_SCRIPTS/Instalar-APKs.ps1
   - O copiar manualmente los .apk a cada teléfono Android

2. FLASHEO DE ESP32 (10 minutos por dispositivo)
   - Usar Arduino IDE o PlatformIO
   - Ejecutar: 3_FIRMWARE_ESP32/Flashear-ESP32.ps1
   - O subir manualmente los .ino

3. CONFIGURACIÓN DE RED
   - Todos los dispositivos en la misma red Wi-Fi
   - Coordinador inicia el HUB (puerto 8888)
   - Cada estación se vincula con la IP del coordinador

================================================================================
                           SECUENCIA DE PUESTA EN MARCHA
================================================================================

PASO 1: COORDINADOR
- Instalar app-coordinador.apk
- Abrir app → Pestaña NODOS → START HUB
- Anotar la IP que aparece

PASO 2: ESTACIONES (en cada teléfono)
- Instalar app correspondiente
- Pestaña SINCRO → escribir IP del coordinador → VINCULAR
- Esperar diálogo de autorización en el HUB

PASO 3: BLUETOOTH (opcional - modo simulado funciona sin él)
- Cada estación → Bluetooth FAB → emparejar con ESP32 correspondiente
- LED del ESP32 parpadea al conectarse

PASO 4: MODO SIMULADO (recomendado para pruebas)
- En cada app activar "Modo Autónomo"
- O usar el botón "SIMULAR CICLO COMPLETO" en el Coordinador

PASO 5: CICLO COMPLETO
- PLC detecta pallet → Coordinador enruta
- Manufactura procesa
- Calidad valida (ArUco/YOLO simulado)
- Almacén guarda en rack

================================================================================
                           MODO SIMULADO / TEST
================================================================================

El sistema soporta 100% de operación sin hardware físico:

- Activar "Modo Autónomo" en cada estación
- El coordinador tiene botón "SIMULAR CICLO COMPLETO"
- TestModeManager simula respuestas de hardware
- Todos los comandos se ejecutan localmente o vía red simulada

================================================================================
                           COMANDOS SOPORTADOS
================================================================================

PLC:
  PLC:START, PLC:STOP, C:DELIVER|from|to, C:STOP|pos, C:FREE|pos

MANUFACTURA:
  R:HOME, R:MOVE, R:RUN, L:START, L:STOP, GCODE_LOAD

CALIDAD:
  VAL:PASS, VAL:FAIL, ARUCO:GEN, YOLO:DETECT

ALMACEN:
  STO:<pos>, R:RUN STORE <pos>, R:RUN RETRIEVE <pos>

COORDINADOR:
  ABORT (global), START_HUB, AUTHORIZE, REJECT
