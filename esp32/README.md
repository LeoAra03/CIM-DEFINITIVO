# ESP32

Aquí van todo lo relacionado con los dispositivos ESP32.

## Contenido
- [firmware](firmware/): firmware listo para cargar y carpetas de soporte
- [scripts](scripts/): scripts y archivos de trabajo del ESP32
- [firmware/Firmware_Support](firmware/Firmware_Support/): soporte adicional y herramientas

## Uso rápido
- abrir [firmware](firmware/)
- cargar el firmware con Arduino IDE o PlatformIO
- revisar los logs en [logs](../logs/)
