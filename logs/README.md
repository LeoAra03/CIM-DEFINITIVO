# Logs

Aquí se pueden dejar los logs del sistema, de las apps y del ESP32.

## Recomendación
- guardar capturas de consola
- guardar logs de instalación o depuración
- mantenerlos ordenados por fecha o por módulo

## Carpetas sugeridas
- [esp32](esp32/): logs del firmware y pruebas del ESP32
- [android](android/): logs de instalación o ejecución de las apps
